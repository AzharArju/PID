Made in sophomore year of high school.

I was trying to learn how PIDs work because I was going to integrate my own onto a drone.
Wrote code in C++, used SFML to draw the graphics onto a window and run the sim.
It's just a square that you give a goal to and it goes to that goal using PID calculations.
Has a clamp to prevent integral from overwinding and whatnot.
High FPS makes the plant be stable at the goal much faster. There is a small steady state error but it goes away after a while.
Wrote the entire thing myself.
